# 🧭 Lab Guide

## 🎯 Goal
Build a solution using GitHub Copilot step-by-step.

---

## ⏱️ Timeline (80 mins)

- 0–20 min → Feature 1
- 20–40 min → Feature 2
- 40–60 min → Feature 3
- 60–75 min → Feature 4
- Last 5 min → Demo preparation

---

## 💡 Tips

- Use small Copilot prompts
- Do not try to build everything at once
- Follow Feature Ladder strictly
- If stuck, ask facilitator

---

## 🎤 Demo Instructions

- Show working features
- Explain approach
- Show at least 1 Copilot prompt
