# 🧭 Lab Guide

## 🎯 Goal
Build solutions for all 3 challenges using GitHub Copilot step-by-step.

---

## ⏱️ Timeline (80 mins)

### 🧩 Work on ALL 3 challenges (incrementally)

- 0–25 min → Challenge 1 (Aircraft Maintenance Tracker)
  - Complete Feature 1 & Feature 2

- 25–50 min → Challenge 2 (Fleet Delivery Tracker)
  - Complete Feature 1 & Feature 2

- 50–70 min → Challenge 3 (Patient Flow Tracker)
  - Complete Feature 1 (minimum) + try Feature 2

- Last 10 min → Improve any one challenge + Demo preparation

---

## 💡 Tips

- Use small Copilot prompts
- Do not try to build everything at once
- Follow Feature Ladder strictly
- If stuck, ask facilitator
