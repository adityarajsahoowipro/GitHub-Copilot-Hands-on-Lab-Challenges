Contribution for Challenge 1: Incident Response and Root Cause Analysis Platform

Contents:
- Project1/backend: Spring Boot MVC API with in-memory incident, RCA, activity timeline, and RCA follow-up action support.
- Project1/frontend: Vite React incident-response dashboard and workflow UI.

Run backend:
cd Project1/backend
mvn spring-boot:run

Run frontend:
cd Project1/frontend
npm install
npm run dev
