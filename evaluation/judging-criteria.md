# 🏆 Judging Criteria

## Scoring (100 Points)

- Feature 0 — App Running → 5
- Feature 1 — Core Functionality → 20
- Feature 2 — Enhancement → 20
- Feature 3 — Smart Feature → 25
- Feature 4 — Robustness → 20
- Feature 5 — Bonus → 10

---

## ✅ Demo Checklist

Each one should show:
- Basic functionality working
- Status update / core logic
- One advanced feature
- How they used GitHub Copilot

---

## 🎯 Evaluation Focus

- Completeness
- Code quality
- Copilot usage
- Demo clarity
